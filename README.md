# El-espejismo-de-la-sustancia
El espejismo de la sustancia: Gramática, formalismo y estratificación en el discurso científico. Santiago Tristany. Este libro audita la reificación —tratar relaciones o modelos como sustancias— en la lógica, física clásica, mecánica cuántica y sistemas normativos. Mediante la estratificación de niveles y la verificación formal (Lean 4, Z3, Clingo).
